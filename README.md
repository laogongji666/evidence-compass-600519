# 证据罗盘｜单股诊断 MVP

面向希望快速核查上市公司财报的个人投资者与研究员。样例公司为贵州茅台（600519.SH）。页面支持输入问题、切换报告期、查看证据卡片和钻取原始财报。

## 启动

纯静态站点，无环境变量或依赖。运行 `npx serve dist`，或用任何静态文件服务器托管 `dist/`。直接打开 `dist/index.html` 也可使用主要功能。

## 数据来源

- [贵州茅台 2026 年半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-15/1225475868.PDF)，披露于 2026-08-15；使用第 5、8、34 页等字段。
- [贵州茅台 2025 年年度报告](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-04-17/600519_20260417_9QS4.pdf)，披露于 2026-04-17；使用主要会计数据与现金流说明。

财报原值存放在 `dist/app.js` 的 `DATA.raw` 中，保留人民币元精度。页面以亿元展示，显示值四舍五入到一位小数；同比用原值计算后保留两位小数。2026 半年度同比比较 2025 同期；2025 全年同比比较 2024 全年，避免跨期混算。

## 核心设计与 AI 角色

1. 用户输入问题，当前 MVP 使用可审计的关键词规则路由到收入、利润、现金流或缺失维度。无法识别时明确提示覆盖范围。
2. 指标计算由确定性 JavaScript 完成；事实卡片展示原始字段和公式。
3. AI 协助起草解释文案，开发过程中逐条对照财报复核。线上 MVP **没有实时大模型调用**，不会暗示生成了新的实时研究结论。
4. 证据分为事实、分析推断、矛盾信号和待验证。重要数字可打开财报对应页。

## 已知边界与未做事项

- 仅一只预设股票；未接入扶摇/iFinD 实时 API，数据是从公开财报核验后录入的固定快照。
- 没有同日股价、估值、行业比较、复权行情与动态公告，界面明确展示为待验证。
- 公司类型适配目前仅覆盖白酒公司的财报问题；不提供投资评级、涨跌预测或买卖建议。
- 外部 PDF 由原站托管，若原站链接失效，需更新来源 URL。

## AI 使用与验证记录

- 使用 Codex 协助界面、前端代码和解释文案起草。
- 逐项对照 2026 半年报核对营业收入、归母净利、经营现金流、营业成本及销售商品收到的现金，并核对管理层对现金流变动的解释。候选人提交前仍应亲自复核这些字段与演示页面。
- 修正了“经营现金流显著增长即白酒销售回款大幅改善”的不合理推断：财报明确涉及集团财务公司的存款项目，页面把此项标为矛盾信号。
- 未把 AI 草稿中的估值和行业结论放入产品，因为缺少同一时点的价格和同行证据。

## 测试说明

- 主链路：输入“现金流改善能否说明经营变好”，应显示现金流解释；切换至 2025 全年应同步更新数据和结论；点击证据卡片应显示原始字段和 PDF 来源。
- 缺失条件：输入“估值是否合理”应显示待验证，不生成估值结论。
- 边界问题：输入超出覆盖范围的问题，应提示可研究范围；页面不显示买卖指令。
- 源站异常：PDF 外链不可用时，原始字段与披露日期仍在页面，但原文钻取受源站影响。
